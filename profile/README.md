**Preserving and Enhancing the Original Xbox Experience**

Welcome to the official GitHub organization for **TeamUIX**. We are dedicated to reviving and modernizing the original Xbox experience through community built tools and mods. Our mission is to preserve the legacy of the Xbox modding scene while developing new utilities, dashboards, and documentation for future generations of enthusiasts.

---

## 🔧 Main Projects

### 🟢 UIX Lite
A modern revival of the classic UIX dashboard. Lightweight, fast, and designed for today’s softmodding standards.
- Fully customizable
- Insignia Compatible
- 720p60fps thanks to [Team Resurgent](https://github.com/Team-Resurgent)
- Extended Partition Support (Standard F/G, but also Dual HDD support)
- Native support for title icons, fonts, and skins.

➡️ [UIX Lite on GitHub](https://github.com/OfficialTeamUIX/UIX-Lite)

---

### 🧰 UIX Lite Toolbox
Previously known as **UIXLiteFTPd**, this on-console utility adds deep customization, file management, theming, and diagnostic features to your UIX Lite installation.
- Built-in FTP server and PrometheOS base thanks to [Team Resurgent](https://github.com/Team-Resurgent)
- Dashboard skin swapping
- Downloader and update tools
- Game Icon Generation

➡️ [UIX Lite Toolbox on GitHub](https://github.com/OfficialTeamUIX/UIX-Lite-Toolbox)

## 🧠 About TeamUIX

TeamUIX grew out of the original Xbox Dashboard mods from the early modding scene. Our mission is to:
- Preserve dashboard modding history
- Build functional, modern tools
- Offer up a kick ass dashboard experience

We’re dedicated to keeping the scene alive with open source mods, documented scripts, and accessible projects. No proprietary lock in, no paywalls, no BS.
